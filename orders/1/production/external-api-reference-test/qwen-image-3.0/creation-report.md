# Qwen Image 3.0 多参考图创作报告

## 结论

本轮完整流程成功：三张本地参考图以 Base64 直接输入 API，生成无字蓝幕原图，转换为真实透明 PNG，再由本地排字脚本生成“开心”成品。结果通过单张试作门禁，可作为外部 API 多图参考路线的有效样例。

## 输入角色

1. `photo-02.jpg`：宠物身份参考，提供白色毛色、脸型、眼睛、耳朵与粉色鼻部证据。
2. `photo-04.jpg`：宠物身份参考，提供全身比例、体型与四肢证据；照片中的衣服和室内背景明确排除。
3. `reference/奶牛贱贱猫.jpg`：仅作风格技法参考，提炼粗粒蜡笔线条、扁平填色、简化比例、动作线与喜剧节奏。

禁止从图3继承原奶牛猫身份、黑色脸部花纹、具体动作、对勾叉号、道具、文字、平台水印或账号。

## 后处理

- API 原图：蓝幕 PNG。
- 自动透明化：从四角估计实际蓝幕颜色，移除背景并对半透明边缘去蓝溢色。
- 透明结果：RGBA，alpha 范围 0–255；四角 alpha 全部为 0。
- 像素统计：720,280 个完全透明像素、9,827 个半透明边缘像素、318,469 个完全不透明像素。
- 非透明包围盒：`(133, 90)–(903, 907)`；四边均满足 Skill 的 8% 最低安全边距，但没有完全达到提示词中更严格的 12% 目标。
- 中文“开心”由本地字体脚本叠加，未要求图像模型生成汉字。

## 批量化前调整

下一轮建议保持同样三图角色分工，把主体高度缩小约 6% 并整体上移约 5%，为底部文案留出更稳定空间；其余身份、结构和透明化参数可以沿用。
