创作要求：把图1和图2中的“奶酪”重新创作为一张原创“开心”宠物表情贴纸。半眯的明亮笑眼，短圆小嘴微笑，右前爪从右侧胸肩自然抬起挥手，另一个前爪清楚连接左侧胸肩并落地；两只后爪均清楚可见且稳定支撑。可有两三条简短手绘动作线，但不要文字、符号、爱心、道具或场景。
