# 外部 API 生图测试报告

## 结论

- 接口接入：通过。`qwen-image-3.0` 原生 DashScope 工作空间端点成功返回图片，服务端生成耗时 7.51 秒。
- 透明背景：通过本地蓝幕后处理达成。输出为 1024×1024 RGBA PNG，四角 alpha 均为 0。
- 正式生产门禁：不通过。本轮仅证明外部 API 与透明化链路可用，当前图片不可并入正式十张套图。

## 与当前内置生成版本对比

当前内置版 `no-caption/07-received.png` 在宽扁头身比、表情的贱萌感、动作符号简洁度和整体贴纸感上更接近已确认方向。外部版优势是生成速度快、结构大体稳定；短板是身份/风格锚定弱，且未遵守四肢完整与安全留白硬约束。

## 后续使用建议

外部接口可以保留为可选生成后端，但必须继续经过“姿态卡 → 四肢/尾根计数 → 透视/遮挡 → 透明化 → 人工视觉 QA”的完整门禁。正式批量切换前，应优先测试支持多图参考的模型或编辑模型，让宠物身份图、风格档案和同套锚点成为图像输入，而不是只依赖文字提示。
