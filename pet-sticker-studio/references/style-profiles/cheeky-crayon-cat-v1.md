# 贱萌蜡笔涂鸦猫（v1）

以粗粝蜡笔线、扁平低细节色块、超大扁头与短小身体为核心的贱萌猫咪表情包风格；强调半眯眼、笨拙动作、稀疏动态线和大量留白，仅学习视觉规律，不复用参考角色的花纹、构图、道具或水印。

状态：draft

## 正向要求

- 使用黑色或深灰色干蜡笔质感轮廓，边缘允许自然颗粒和轻微抖动，但主体轮廓必须闭合清晰
- 角色采用超大、偏宽偏扁的头部与极短小身体，四肢简化为短圆块面，整体低重心
- 铺色以扁平哑光色块为主，保留纸面或蜡笔颗粒感，基本不使用写实毛发、渐变光影或体积渲染
- 眼睛采用简洁的暖芥末金或宠物真实眼色派生色块，通过半眯、下垂、放大等方式表达情绪
- 嘴形、耳势、短肢动作与少量手绘动作线共同形成笨拙、贱萌、略带无语感的喜剧节奏
- 单只角色居中，占正方形画布约 62%–72%，四周保留至少 14% 留白，最终输出真实透明背景
- 宠物身份特征优先于风格参考：保留真实毛色、眼色、耳色、鼻色、体型和稳定花纹
- 文案在无字主体确认后由脚本单独叠加，不要求图像模型直接生成中文

## 负向约束

- 不复制参考角色的奶牛猫黑色分区、左右脸设计、固定表情、固定动作或具体构图
- 不复制参考中的对勾、叉号、纸张、道具、账号、平台水印、签名或任何文字
- 不把白色宠物改成黑白花猫，不添加现实照片中不存在的稳定毛色或不对称标记
- 不使用精致数字厚涂、照片级毛发、3D 渲染、强光影、复杂背景或高光塑料质感
- 不出现多肢、多耳、多尾、融合爪、漂浮部件、乱码、品牌、IP 或已知角色元素
- 不模仿任何具体在世艺术家，不将参考图片当作宠物身份来源
