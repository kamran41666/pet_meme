# 飞书表单接入操作手册

## 目标

完成后，客户提交飞书表单，商家在 `PetMemeStudio.exe` 点击一次同步，程序自动读取需求与照片、建立本地订单、刷新订单台账，并将本地订单编号回写飞书。

## 第一步：建立多维表格和表单

1. 在飞书新建一个多维表格，命名为“宠物表情包客户订单”。
2. 按 `飞书表单字段配置清单.csv` 建立字段。字段名称建议一字不改。
3. 新建“表单视图”，把“表单状态”和“本地订单编号”设为客户不可填写；其余客户字段按清单设置。
4. 把“案例展示授权”的默认选项设为“不同意”。
5. 把“照片权利确认”设为必填；只有选“是”的订单才能生产。
6. 在表单说明中写明只接受单只猫或狗、固定十张、5–8 张清晰参考图。
7. 发布表单并用自己的宠物提交一笔测试记录。

## 第二步：创建飞书企业自建应用

1. 打开飞书开放平台开发者后台。
2. 创建“企业自建应用”，名称可用“宠物表情包订单同步”。
3. 在权限管理中搜索并开通与以下能力对应的权限：
   - 查看多维表格及记录；
   - 编辑多维表格记录；
   - 查看/下载云文档图片和附件。
4. 创建并发布一个应用版本。如果企业管理员审批权限，需要完成审批。
5. 回到目标多维表格，在右上角更多菜单中选择“添加文档应用”，把刚才的应用添加进去并授予可编辑权限。
6. 在应用的“凭证与基础信息”页面取得 App ID 和 App Secret。

不要把 App Secret 写进飞书表格、订单文件、截图或聊天。只在本机程序的密码框内输入。

## 第三步：取得多维表格链接

打开实际数据表，复制浏览器地址栏完整链接。标准链接类似：

```text
https://your-company.feishu.cn/base/appXXXXXXXX?table=tblXXXXXXXX&view=vewXXXXXXXX
```

其中 `/base/` 后面是 App Token，`table=` 后面是 Table ID。程序可以从完整链接自动提取，无需手抄。

如果链接是 `/wiki/` 而不是 `/base/`，首版程序不能直接从 wiki 节点推导真实 App Token。最简单的处理方式是把多维表格移动/复制为普通多维表格，或者在飞书 API 调试台取得真实 App Token 后手工填写。

## 第四步：在程序中检查连接

1. 双击 `dist/PetMemeStudio.exe`。
2. 进入“飞书表单同步”。
3. 粘贴多维表格完整链接。
4. 输入 App ID 和 App Secret。
5. 点击“检查连接与字段”。
6. 程序会返回：连接是否成功、字段总数、缺少的客户必填字段、缺少的建议字段，以及是否具备状态回写条件。
7. 若提示缺字段，回飞书补齐后重新检查。

## 第五步：完成第一笔闭环联调

1. 点击“读取未处理表单”。
2. 程序只展示没有“本地订单编号”、且状态不是已同步/生产中/已交付的记录。
3. 点击目标记录的“带入订单”。
4. 检查客户信息和授权。飞书附件会在保存订单时自动下载，因此无需再次手选图片。
5. 点击“保存并建立订单”。
6. 成功后应同时出现以下结果：
   - 本地新增 `orders/PS-日期-序号/`；
   - 目录中存在 `input/`、`order.json`、`intake.json`、`status.json`；
   - `outputs/订单总表-程序同步.csv` 出现新订单；
   - 飞书原记录的“表单状态”变为“已同步”；
   - 飞书原记录的“本地订单编号”出现 PS 编号。
7. 在生产队列点击“检查能否开工”，人工确认正脸、侧脸、全身和清晰度。
8. 点击“开始两张试作”，Codex 开始身份卡和两张样图流程。

## 常见错误

### 鉴权失败

检查 App ID/Secret 是否来自同一个应用、应用是否已发布、管理员是否批准权限。

### 没有权限访问多维表格

仅在开放平台开权限还不够，还需要把应用添加为这份多维表格的文档应用。

### 能读记录但附件下载失败

补充云文档附件读取/下载权限，重新发布应用版本，再检查文档应用权限。

### 本地建单成功但回写失败

确认应用有编辑记录权限，并确认表中存在完全同名的“表单状态”和“本地订单编号”。本地订单不会因此丢失，不要再次建单；修复权限后可在飞书手工补上编号。

### 同一记录提示已经建立过订单

这是防重复保护。到程序左侧最近订单或 `outputs/订单总表-程序同步.csv` 查找对应的飞书记录编号。

## 当前自动化边界

当前是“人工点击同步 + 自动处理”，不需要服务器，也不会在电脑关机时运行。若以后需要飞书表单一提交就自动执行，下一阶段再增加飞书事件订阅、云函数和生产队列。
